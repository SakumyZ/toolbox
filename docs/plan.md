### 一、系统工具类

#### 1. Windows 服务管理器 ⭐ 优先级：高

> 用户明确需求

当前状态：🟡 部分完成（已支持列表、搜索筛选、收藏、单项启停重启、分组批量启停；未支持服务描述展示、启动类型修改、实时状态轮询/WMI 监听）

**功能：**

- 列出所有 Windows 服务（名称、状态、启动类型、描述）
- 启动 / 停止 / 重启服务
- 修改启动类型（自动 / 手动 / 禁用）
- 搜索 + 筛选（按状态、按名称关键字）
- 常用服务置顶/收藏（如 MySQL、Redis、IIS、Docker Desktop Service）
- 一键批量启停（场景化：如"启动开发环境"一键启动 MySQL + Redis + Nginx）

**技术要点：**

- `System.ServiceProcess.ServiceController` API
- 需要管理员权限（启停操作时提权）
- 实时状态轮询或 WMI 事件监听

#### 2. 端口占用查看器 ⭐ 优先级：高

> 开发常见痛点：端口被占用不知道是哪个进程

当前状态：✅ 已完成（当前规划内核心能力已具备）

**功能：**

- 列出所有监听中的 TCP/UDP 端口
- 显示占用进程（PID、进程名、路径）
- 搜索特定端口号
- 一键结束占用进程
- 常用端口高亮标记（80, 443, 3000, 3306, 5432, 6379, 8080...）

**技术要点：**

- `netstat` / `GetExtendedTcpTable` Win32 API
- `Process.GetProcessById` 获取进程信息

#### 6.5 脚本管理器 ⭐ 优先级：高

> 面向本地脚本资产管理，兼顾参数化运行与后续扩展

当前状态：🟡 部分完成（已支持脚本导入、参数表单配置、直接运行、输出查看、执行历史与过期日志清理；未支持文件/目录选择器参数、收藏/分组）

**功能：**

- 新建脚本定义，录入名称、说明、工作目录
- 导入并托管 `.bat` / `.ps1` / `.sh` 脚本文件
- 为脚本配置参数定义：参数名、展示名、参数类型、默认值、是否必填、命令行参数名
- 根据参数定义自动生成运行表单
- 直接运行脚本并展示 stdout / stderr / exit code
- 统一托管脚本文件，避免依赖原始散落路径

**技术要点：**

- SQLite 持久化 `Scripts` 与 `ScriptParameters`
- 脚本文件复制到 `LocalAppData\ToolBox\Scripts\{id}\`
- `.bat` 通过 `cmd.exe /c` 运行，`.ps1` 通过 `powershell.exe -ExecutionPolicy Bypass -File` 运行
- PowerShell 脚本优先使用 `pwsh.exe`，找不到时再回退到 `powershell.exe`
- `.sh` 预留 Shell 扩展能力，优先探测 `bash.exe` / `sh.exe`
- 首版参数控件类型限制为单行文本 / 多行文本 / 布尔，避免表单设计复杂度失控
- 脚本可选配置“命令前缀”，按原样拼接在脚本路径前，兼容 `python`、绝对路径解释器、`uv run` 等习惯
- 参数编辑器下拉以"中文名(English)"格式显示控件类型

**本轮实装清单：**

- [x] 新增“脚本管理器”导航入口与管理页面
- [x] 新增脚本定义与参数定义持久化表
- [x] 支持导入 `.bat` / `.ps1` / `.sh` 脚本文件
- [x] 支持参数定义的新增 / 编辑 / 删除
- [x] 支持根据参数定义动态生成运行表单
- [x] 支持直接运行脚本并展示输出结果
- [x] 支持一键打开脚本托管目录
- [x] 兼容系统编码读取脚本输出，避免不改脚本时的乱码问题
- [x] 布尔型参数显式传递 `true/false`，不再因 `false` 被省略
- [x] 支持命令预览与一键复制，便于在外部终端复现执行

> 在公司 / 个人等多套 SSH config 之间快速切换，避免手动注释

当前状态：✅ 已完成（首版）

**功能：**

- 保存多套 SSH config 预设
- 支持新增 / 编辑 / 删除预设
- 支持从当前 `C:\Users\housei\.ssh\config` 导入为预设
- 点击预设后直接覆盖当前 ssh config
- 自动备份当前 config，避免误覆盖
- 显示当前生效预设与预设内容预览
- 后续预留规则级控制扩展位

**技术要点：**

- SQLite 持久化预设元数据与整份 config 文本
- 文件写入前进行基础校验
- 切换时自动备份 `config.backup.yyyymmddHHmmss`
- 首版采用“预设覆盖式”，暂不做逐 Host 规则级编辑

#### 8. Skill 管理器 ⭐ 优先级：高

> 用于控制 agent 可见的 skill 范围，减少误用与串用

当前状态：✅ 已完成（首版）

**功能：**

- 扫描启用目录中的全部 skill 文件夹并展示
- 扫描停用目录中的全部 skill 文件夹并展示
- 使用 `ToggleSwitch` 一键启用 / 停用 skill
- 停用时将 skill 文件夹移动到停用目录，启用时移动回启用目录
- 启用时自动向配置的多个 Agent 目录分发软链接，停用时同步移除软链接
- 支持配置启用目录与停用目录（默认 `~\.agents\skills` 与 `D:\Backup\AI\skills`）
- 支持配置多个目标 Agent 目录（如 `~\.claude\skills`, `~\.openCode\skills`）
- 支持为 skill 设置别名，列表优先展示别名
- 支持为 skill 设置分类，分类支持下拉选择或输入新分类（清空为未分类）
- 支持自定义分类颜色，新建无颜色时自动回退为主题蓝，预设颜色与取色器结合并在列表中展示分类颜色标识
- 新增独立的「分类管理器」，支持集中重命名或删除废弃分类
- 支持按名称 / 别名 / 描述搜索，按分类与状态筛选
- 列表纯按名称排序，不再强制启停状态置顶
- 支持彻底物理删除无用的 Skill 以及清理数据库
- 支持将废弃 Skill 归档并隐藏，提供独立的归档管理器供恢复或彻底删除
- 自动读取 `SKILL.md` 描述作为列表说明

**技术要点：**

- 文件夹级目录扫描与移动实现启停切换
- SQLite 持久化目录配置、skill 别名与分类信息
- 页面内进行状态筛选、分类筛选与搜索过滤
- 目标目录冲突保护，避免覆盖已有 skill 文件夹

- SSH 预设管理与快速切换 (`t ssh list`，`t ssh use <Name_or_ID>`)
- 脚本可视化注册为 CLI 指令并动态匹配路由。用户可在桌面端“脚本管理器”界面中为任何脚本一键注册自定义的终端 CLI 路径（如 `shell sync` 或 `excel md`）
- “双剑合璧”命令行参数智能解析：支持“位置参数”与“命名 Flag 参数”的双重优先匹配与自适应绑定
- 重定向流原始字节异步自适应高保真解码器：以 UTF-8 优先 ➡️ 自动降级至系统当前代码页（如 GBK）解码，彻底消灭不同异构子进程的 Emoji/Unicode 框线符号丢失与中文整句乱码
- C# 桌面端主程序启动时后台静默一键 PATH 检测与注册

**技术要点：**

- `<UseWinUI>` 独立控制台项目配合文件 Link 编译，零侵入、零修改实现对主程序逻辑模型的共享
- .NET 8.0 独立控制台在 Main 启动时显式注册 `System.Text.CodePagesEncodingProvider` 以完美支持 CP936 国家语言包
- 摒弃 .NET `OutputDataReceived` 异步事件（避免解码器锁死），直接对子进程 `BaseStream` 异步读取原始 `byte[]` 字节流并按行分割与自适应解码
- 主应用 `MainWindow` 构造函数中使用 `Task.Run` 异步获取运行环境并对 Registry 中的用户 PATH 执行幂等追加
